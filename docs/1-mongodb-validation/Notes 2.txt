### **Step: “Query efficiency + filtered analytics”**

We now show that **indexes + analytics work together**.

### 🔹 Step 4A — Filtered aggregation (realistic NLP use)

**Top words ONLY for one meeting**

```javascript
db.turns.aggregate([
  { $match: { meeting_id: 1 } },
  { $project: { words: { $split: ["$text", " "] } } },
  { $unwind: "$words" },
  { $group: { _id: "$words", count: { $sum: 1 } } },
  { $sort: { count: -1 } },
  { $limit: 5 }
])
```
