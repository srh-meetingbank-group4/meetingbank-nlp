## 4A — Count turns per meeting

### Pipeline (COPY–PASTE STAGE BY STAGE)

**Stage 1 (Group):**

```json
{
  $group: {
    _id: "$meeting_id",
    num_turns: { $sum: 1 }
  }
}
```

## 4B — Word frequency (NLP-style aggregation)

Add **NEW aggregation** (clear pipeline).

### Stage 1 — Split text

```json
{
  $project: {
    words: { $split: ["$text", " "] }
  }
}
```

### Stage 2 — Unwind

```json
{
  $unwind: "$words"
}
```

### Stage 3 — Group

```json
{
  $group: {
    _id: "$words",
    count: { $sum: 1 }
  }
}
```

### Stage 4 — Sort

```json
{
  $sort: { count: -1 }
}
```

### Stage 5 — Limit

```json
{
  $limit: 5
}
```

Run pipeline.
