7.1 — Meeting-level sentiment summary (aggregation)

Run this in MongoDB shell or Compass:

db.nlp_sentiment.aggregate([
  {
    $group: {
      _id: "$meeting_id",
      avg_sentiment: { $avg: "$score" },
      positive_ratio: {
        $avg: {
          $cond: [{ $eq: ["$label", "POSITIVE"] }, 1, 0]
        }
      },
      negative_ratio: {
        $avg: {
          $cond: [{ $eq: ["$label", "NEGATIVE"] }, 1, 0]
        }
      },
      num_turns: { $sum: 1 }
    }
  }
])


This gives you:

average sentiment

positivity vs negativity

turn counts

7.2 — City-level sentiment (this is a WOW query)
db.nlp_sentiment.aggregate([
  {
    $lookup: {
      from: "meetings",
      localField: "meeting_id",
      foreignField: "meeting_id",
      as: "meeting"
    }
  },
  { $unwind: "$meeting" },
  {
    $group: {
      _id: "$meeting.city",
      avg_sentiment: { $avg: "$score" },
      total_turns: { $sum: 1 }
    }
  }
])
