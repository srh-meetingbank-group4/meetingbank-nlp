
---

### Query 2: Count meetings by city

```js
db.meeting_media.aggregate([
  {
    $group: {
      _id: "$city",
      count: { $sum: 1 }
    }
  }
])
```

📸 **Screenshot #3**

---

### Query 3: Join with meetings (LOOKS ADVANCED)

```js
db.meeting_media.aggregate([
  {
    $lookup: {
      from: "meetings",
      localField: "meeting_id",
      foreignField: "meeting_id",
      as: "meeting_info"
    }
  }
])
```

📸 **Screenshot #4**

* You can link structured + unstructured data
* MongoDB handles heterogeneous schemas well
