## 2️⃣ What to write (copy this structure, adapt wording)

### A. Why PostgreSQL was used

You already did this — now explain it.

Write something like:

> PostgreSQL was used to store structured, relational data such as meetings and transcript turns. It enforces schema constraints, referential integrity, and supports transactional consistency, making it suitable for core data ingestion and validation.

Key points to mention (bullet form in report is fine):

* Strong schema
* Referential integrity
* Reliable ETL
* Deterministic structure

---

### B. Why MongoDB was introduced

This is the **key argument**.

Write:

> MongoDB was introduced to support text-heavy analytics and NLP-style workloads. Transcript turns are semi-structured and require frequent text search, aggregation, and filtering operations, which are more naturally supported by MongoDB’s document model and aggregation framework.

Mention explicitly:

* `$text` search
* Regex queries
* Aggregation pipeline
* No JOIN overhead
* Schema flexibility

---

### C. Why NOT only PostgreSQL (this is important)

One short paragraph:

> While PostgreSQL supports full-text search, implementing NLP-style queries requires additional preprocessing such as tsvector generation and complex joins. MongoDB enables faster iteration for exploratory text analytics and NLP preprocessing without modifying schema.

This shows you **thought critically**, not blindly.
